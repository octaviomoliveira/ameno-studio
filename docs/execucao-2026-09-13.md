Base: `7dba1e0`, revisão documental sobre o estado de aplicação `6e0da9e`.
As cinco tarefas da especificação enviada em 13/09 foram concluídas na ordem,

## Alterações

1. Intro: tamanho e cores solicitados; a animação exclusiva do hint termina em
   opacidade 0,5 para que o antigo keyframe de opacidade 1 não sobreponha a regra.
2. Hero: nova cópia VP9 para scrubbing, original preservado; referência alterada
   em `src/app/page.tsx`, onde `videoSrc` efetivamente é definido.
3. Portfólio: estrutura linear com cinco projetos, Keywords Wall e assets.
   GSAP ScrollTrigger é o único responsável pelo movimento horizontal/pin dos
   projetos. Distância medida por `track.scrollWidth - trackWrap.clientWidth`,
   slides de 80vw, sem snap. IDs, dados, imagens e metadados preservados.
   Não existem rotas individuais de projetos; nenhum link foi inventado.
4. Keywords Wall: apenas tipo/valores de `cls`, aplicação no botão e novas
   classes globais. O CSS module, os eventos, portal, rail e acessibilidade
   existentes foram preservados. O vermelho do hover continua ativo.
5. Assets: nova seção para a Cadeira Raia, reutilizando o viewer Three.js/Draco
   existente, seus controles e fallback, com importação dinâmica no cliente.

Adaptações de integração: `preload` substitui a propriedade obsoleta `priority`
do exemplo; alturas são explicitamente liberadas no fallback vertical; viewer
preenche seu wrapper; estilos de assets são escopados para evitar conflitos com
regras antigas. Nenhuma dependência do projeto foi instalada ou atualizada.

## Vídeo

FFmpeg/ffprobe 9.0.1, instalado via Winget antes desta execução.

| Medida | Original | Cópia para scrub |
| --- | --- | --- |
| Codec / resolução / FPS | VP9 / 1280×720 / 24 | VP9 / 1280×720 / 24 |
| Frames de vídeo | 361 | 361 |
| Keyframes | 3 | 25 |
| Intervalo de keyframes | aproximadamente 5,333 s | 0,625 s (15 frames) |
| Tamanho | 15.788.944 bytes | 5.216.442 bytes |
| Bitrate médio de vídeo | aproximadamente 8,19 Mbps¹ | aproximadamente 2,77 Mbps |
| Áudio | Opus | removido conforme especificação |

¹ O stream não informa `bit_rate`; valor calculado pela soma dos bytes dos
pacotes de vídeo dividida pela duração visual de 15,042 s. O bitrate total do
container original é 8,35 Mbps. `r_frame_rate` e `avg_frame_rate`: `24/1`;
`codec_tag_string`: `[0][0][0][0]`.

```text
ffmpeg -hide_banner -nostdin -n -i public/hero/hero-central-parque.webm -c:v libvpx-vp9 -b:v 2M -crf 33 -g 15 -row-mt 1 -an public/hero/hero-central-parque-scrub.webm
```

A comparação SSIM de todos os frames resultou em 0,964028. O valor é uma
medida de similaridade, não uma afirmação de compressão sem perda.
